# Four Dots

A browser game inspired by Two Dots. Connect matching dots, make loops to create bombs, and clear the board with special dots.

## How to Play
- Drag across adjacent dots of the same color.
- Release to clear the chain.
- Make a loop to turn enclosed dots into bombs.
- Bombs explode after dots settle (plus a short delay), clearing a 1-dot radius.

## Controls
- Click/drag to connect dots.
- Cheat Mode (optional): toggle and triple-click a dot to remove it without spending a move.

## Run Locally
Open `index.html` in a browser.

## Notes
- Includes Matter.js for fall animation.
- Sound effects are generated with Web Audio.
